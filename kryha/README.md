# КРИГА — сайт свічок ручної роботи

Статичний сайт на 4 сторінки: без збірки і без бібліотек. Відкривається будь-яким браузером, хоститься безкоштовно на GitHub Pages або Cloudflare Pages.

```
index.html      Головна
catalog.html    Каталог
about.html      Майстерня
delivery.html   Доставка, оплата, FAQ
css/style.css   Увесь дизайн (кольори — на початку файлу, у :root)
js/config.js    Посилання на Instagram/Telegram і адреса бота
js/products.js  Товари, ціни, фото, відгуки
js/main.js      Логіка (міняти не потрібно)
worker/         Код бота для заявок у Telegram
img/            Сюди кладіть свої фото
```

## Як змінити тексти, ціни і фото

- **Ціни, назви, описи товарів** — `js/products.js`. Кожен товар — окремий блок.
- **Фото товару** — покладіть файл у `img/` (наприклад `img/brila.jpg`) і впишіть у товар `img: 'img/brila.jpg'`.
- **Фото на сторінках** — знайдіть у HTML блок
  `<div class="ph" ...><span>Опис фото</span></div>`
  і замініть його на `<img src="img/ваше-фото.jpg" alt="Короткий опис фото">`.
  Текст у `<span>` підказує, яке саме фото туди потрібне.
- **Тексти** — прямо в HTML-файлах.
- **Відгуки** — `js/products.js`, список `KRYHA_REVIEWS`. Додавайте тільки справжні.
- **Instagram і Telegram** — `js/config.js`.

### Що обов'язково заповнити
Пошукайте в файлах `class="todo"` — це місця під ваші дані (час горіння, способи оплати, історія про вас). Також:
- `burn` у товарах `js/products.js` — час горіння після ваших тестів;
- адресу сайту `kryha.com.ua` у `<head>` кожної сторінки (canonical і og:image) — замініть на свій домен;
- `img/og.jpg` — картинка 1200×630 для красивого прев'ю, коли посиланням діляться в соцмережах.

Фото найкраще зберігати у JPG або WebP шириною 1200–1600 px і вагою до 300 КБ — тоді сайт швидко відкривається з телефона.

## Як підключити заявки в Telegram

1. **Створіть бота.** У Telegram напишіть [@BotFather](https://t.me/BotFather) → `/newbot` → придумайте ім'я. Він дасть **токен** виду `123456:ABC-...`.
2. **Дізнайтеся свій chat_id.** Напишіть своєму боту будь-яке повідомлення. Потім відкрийте в браузері
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` — знайдіть `"chat":{"id": 123456789`. Це і є **chat_id**.
   (Хочете отримувати заявки в групу — додайте бота в групу, напишіть там щось, і візьміть id групи, він починається з `-`.)
3. **Створіть Worker.** Зареєструйтеся на [Cloudflare](https://dash.cloudflare.com) (безкоштовно) → Workers & Pages → Create → Worker → назвіть, наприклад, `kryha-orders` → Deploy → Edit code → вставте вміст `worker/telegram-worker.js` → Deploy.
4. **Додайте змінні.** У Worker: Settings → Variables and Secrets:
   - `BOT_TOKEN` — токен (тип **Secret**);
   - `CHAT_ID` — ваш chat_id;
   - `ALLOWED_ORIGINS` — адреса вашого сайту, напр. `https://kryha.com.ua` (можна додати пізніше, коли буде домен).
5. **Пропишіть адресу Worker на сайті.** Скопіюйте адресу виду `https://kryha-orders.ваш-нік.workers.dev` у `js/config.js` → `workerUrl`.
6. Відправте тестову заявку з сайту — вона має прийти в Telegram.

Поки `workerUrl` порожній, форма не надсилає заявку, а пропонує написати в Instagram або Telegram.

## Як опублікувати

Найпростіше — **Cloudflare Pages**: Workers & Pages → Create → Pages → підключіть GitHub-репозиторій або просто перетягніть папку `kryha`. Свій домен підключається там же, у Custom domains.
