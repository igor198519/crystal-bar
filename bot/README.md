# Бот-магазин і CRM для свічок ручної роботи

Один файл `Code.gs` для Google Apps Script і Google Таблиця як база. Сервер не потрібен.

Покрокова інструкція запуску — на початку `Code.gs` (≈10 кроків, без програмування).

## Що вміє

**Клієнти:** каталог з фото і варіантами (аромат, колір, розмір, ґніт), конструктор набору зі знижкою, подарункове оформлення (пакування, листівка, без чека, доставка іншому отримувачу), Нова Пошта з пошуком міста і відділення або самовивіз, перевірка дати «потрібно до», оплата monobank (повна або аванс) чи накладений платіж, промокоди, бали і реферальна програма, мої замовлення з трекінгом і повтором, нагадування про покинутий кошик, відгуки з фото, заявки на опт і корпоратив з логотипом, нагадування «свічка догорає», дати близьких.

**Команда:** ролі (2 власники з рівними правами + помічник), кнопка «🙋 Беру» з оновленням картки в обох власників, статуси із журналом, черга виробництва партіями з часом визрівання, автосписання сировини за техкартою, склад, собівартість і маржа, ТТН Нової Пошти в один клік, автотрекінг, пакування з обовʼязковим фото, розсилки за сегментами, звіти, ранкове зведення.

## Сценарії перевірки після запуску

Перед перевіркою: у «Команда» вписані ID Ігоря і Юлії (Власник) та помічника (Помічник), галочка «Активний». Для швидкої перевірки виробництва поставте «Визрівання, год» = 0 (потім поверніть 48).

| Що зробити | Що має статися |

## Що важливо знати

- **Перевірено на імітації.** Логіку бота прогнано в імітації Google Таблиці, Telegram, Нової Пошти і monobank: 89 автоматичних перевірок (повний цикл замовлення, права помічника, оплати, скасування, нагадування) пройшли. У справжніх сервісах перевірте першим тестовим замовленням за сценаріями вище.
- **monobank:** Apps Script не бачить заголовок підпису вебхука, тому бот після кожного вебхука сам перепитує статус інвойсу в API monobank. Повторні вебхуки не дублюють оплату.
- **Telegram і Apps Script:** у `getWebhookInfo` може показуватись помилка 302 — це особливість вебпрограм Google. Повторні оновлення бот відсікає за `update_id`.
- **Ліміт часу Apps Script — 6 хвилин на запуск.** Розсилки до ~2–3 тис. людей встигають; для більших баз розсилайте сегментами.
- **ТТН:** перед першою ТТН запустіть `npSetupSender`. Якщо місто чи відділення вводились вручну (без ключа НП), ТТН вводиться вручну.
- **Фіскальні чеки (ПРРО)** бот не створює — це окрема інтеграція (наприклад, через кабінет monobank).
